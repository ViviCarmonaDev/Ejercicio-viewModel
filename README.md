# Ejercicio-viewModel
 
Reto de la clase: Tu primer ViewModel con Jetpack Compose

Crea una pantalla interactiva desde cero que gestione un contador básico aplicando el patrón de arquitectura recomendado.

Requisitos:

- Crear un ViewModel llamado CounterViewModel que gestione un número entero (Int)
- Crear un Composable llamado CounterScreen que obtenga la instancia del ViewModel.
 - Diseñar la interfaz con un componente Text que muestre el valor actual del contador  iniciado en 0 y un Button con el texto "Incrementar" que incremente el valor en un uno al presionarlo.
